# mcp-math

Routes mathematics tasks to maxima-mcp CAS (Computer Algebra System) tools.

## What it does

When the user asks a mathematics question (solve, differentiate, integrate, plot, etc.), this skill guides Claude to use the correct maxima-mcp tool rather than attempting mental arithmetic or guessing from 100+ available tools.

## Skill

- **math** — Model-invoked skill that activates on any mathematics task and provides a routing table from problem type to the correct MCP tool.
